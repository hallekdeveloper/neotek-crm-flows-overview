# Neotek CRM Flows Overview

Client-facing web app that explains Account, CS Assignment Pool, CS Flow, Refund, and Retention in plain language.

## Run locally

```bash
cd overview-app
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Live

- Site (always use this): https://neotek-crm-flows-overview-three.vercel.app
- GitHub: https://github.com/hallekdeveloper/neotek-crm-flows-overview
- Deploy: `vercel --prod --yes --scope muhammad-waqqas-projects`

## CS Stage Task (updated 24 Aug 2026)

On CS / Health Scores edit: close **all** open CS Stage Tasks on the Account (any stage) with Completed + Close By System. Do not close Sales Order / manual Tasks. Then create a new CS Stage Task for Stages 1–4.
