# Neotek CRM Flows Overview

Client-facing web app that explains Account, CS, Refund, and Retention in plain language.

## Run locally

```bash
cd overview-app
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Tabs

| Tab | Content |
|---|---|
| Overview | All requirements + what is live |
| Account | Account → Contact → CS Specialist |
| CS Flow | CS journey + bank options |
| Refund Flow | Create, eligibility 3/5 days, bank form |
| Retention Flow | Not started — waiting on requirements |
